# Tic-Tac-Toe

A classic Tic-Tac-Toe game developed as a web-based application using HTML, CSS, and JavaScript, designed to provide an interactive two-player gaming experience. The application allows players to take turns marking cells on a 3×3 grid, automatically validates winning combinations across rows, columns, and diagonals, and identifies the winner or a draw. It also includes game reset functionality, enabling players to start a new round seamlessly.
## Features

- Interactive 3×3 game board
- Two-player gameplay
- Automatic winner detection
- Draw detection when all cells are filled
- Reset and New Game options
- Simple and user-friendly interface

## Tech Stack

- HTML5
- CSS3
- JavaScript

## How to Play

1. Player X starts the game.
2. Players take turns selecting empty cells.
3. The first player to align three marks horizontally, vertically, or diagonally wins.
4. If all cells are filled without a winner, the game ends in a draw.
